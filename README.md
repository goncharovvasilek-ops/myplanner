# LinkBoard

Доска со звеньями (фото + подпись или только текст), ниточками-связями и слоями.
Чистый HTML/JS, без сборки и зависимостей. Оформлено как PWA: ставится на домашний экран
iPhone, открывается на весь экран и работает офлайн.

## Файлы

| файл | что это |
|---|---|
| `index.html`, `style.css`, `app.js` | само приложение |
| `manifest.webmanifest`, `icons/` | имя, иконки, полноэкранный режим |
| `sw.js` | service worker — офлайн-кэш |
| `tools/make_icons.py` | перерисовать иконки (Pillow) |

## Запуск на ПК

```
python -m http.server 8765 -d C:\Users\User\Desktop\Projects\LinkBoard
```
и открыть http://localhost:8765. Мышь работает как палец, колесо — масштаб.

## Установка на iPhone

Service worker (офлайн) работает только по **HTTPS**, поэтому приложение нужно один раз
выложить на любой бесплатный статический хостинг:

* **Netlify Drop** — https://app.netlify.com/drop, перетащить папку `LinkBoard` в окно
  браузера. Через несколько секунд будет адрес вида `https://имя.netlify.app`.
  Без входа сайт удаляется примерно через час, так что нужен бесплатный аккаунт.
* **GitHub Pages** — создать публичный репозиторий, залить в него содержимое папки,
  в Settings → Pages выбрать ветку `main`. Адрес: `https://<логин>.github.io/<репозиторий>/`.

Дальше на iPhone:
1. Открыть адрес в **Safari**.
2. Нажать «Поделиться» → **«На экран Домой»** → «Добавить».
3. Запускать с иконки LinkBoard. Приложение откроется на весь экран и будет работать без сети.

Важно:
* Данные хранятся **на телефоне** (IndexedDB), на хостинг ничего не уходит. У приложения
  с домашнего экрана своё хранилище, отдельное от вкладки Safari.
* Пока сайт открыт как обычная вкладка Safari, iOS может стереть его данные после
  долгого простоя. У установленного на экран «Домой» приложения такого ограничения нет.
  Время от времени делайте **Меню → Экспорт** (файл можно сохранить в «Файлы» или iCloud).
* После обновления файлов на хостинге увеличьте `CACHE` в `sw.js` (`linkboard-v2`…).
  Новая версия подхватится со второго запуска.

## Управление

* **＋ Звено** — фото (галерея/камера, ужимается до 1200 px JPEG) и/или моноширинный текст.
* **Двойной тап** по звену — выбрать или снять выбор, можно выбрать несколько. Двойной тап по пустому месту снимает весь выбор.
* Выбранные звенья **перетаскиваются** пальцем. Невыбранные не сдвигаются случайно: по ним палец двигает доску.
* **Ниточка** — тянуть от красного кружка на правом краю звена к другому звену.
* **Тап по ниточке** выделяет её, **Удалить** удаляет выделенные ниточки и звенья.
* **Один палец** — сдвиг доски, **два пальца** — масштаб вокруг точки между пальцами.
* **Слои 1–5** (можно добавить ещё). Тап по номеру переключает слой, тап по названию слоя открывает настройки: переименовать, скрыть слой из подложки, добавить или удалить слой.
* **Перенос** — отметить полупрозрачные звенья с других слоёв и нажать «Перенести».
  Ниточки между перенесёнными звеньями (и между ними и уже лежащими на слое) тоже переносятся.

### Перенос — ссылкой, а не копией

Звено существует в одном экземпляре, а слой хранит список ссылок на звенья и **свои** ниточки.
Почему так:
* фото не дублируется в памяти телефона;
* если исправить подпись или фото, изменение будет видно на всех слоях;
* полупрозрачная копия с прошлого слоя лежит ровно под активным звеном и не двоится.

Цена: если подвинуть звено на одном слое, оно сдвинется и на остальных.
Удаление спрашивает, что сделать: «убрать только с этого слоя» или «удалить со всех слоёв».
